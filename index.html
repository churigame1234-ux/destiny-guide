게임 진행 흐름

승리 목표: 살인마는 설정된 횟수만큼 NPC/유저 살인에 성공하면 승리하고, 시민은 부검, 몸수색, 심증과 동선을 바탕으로 추리하여 투표로 살인자를 검거하면 승리합니다.

플레이어 살인: ON 설정이면 고정 2회 제한 없이 생존자가 4명이 남을 때까지 가능합니다. 다른 사망이 없다면 8인 시작은 최대 4명, 7인은 3명, 6인은 2명, 5인은 1명입니다. 4인 이하는 플레이어 살인 OFF이며, 생존자 4명부터는 추가 플레이어 살인이 차단됩니다. 가스폭파는 이 제한의 예외입니다.

  1. 파밍처음 시작하면 흩어져 아이템 파밍을 합니다. 살인자가 첫 번째 살인을 내기 전까지 진행합니다.
  2. 첫 시체 발견첫 시체를 발견하면 모두를 부른 뒤, 가장 가까운 쓰레기통이 있는 방으로 이동하여 모입니다.
  3. 추리대 진행모인 방에서 직업 공개, 아이템 교환, 시체 부검, 몸수색, 추리 및 심문을 진행합니다.
  4. 재분산정보 교환이 끝나면 다시 흩어지고, 다음 살인이 날 때까지 이리저리 돌아다닙니다.
  5. 반복5살 승리 모드라면 앞의 과정을 3번째 살인이 날 때까지 반복합니다.
  6. 최종 투표3번째 시체를 찾은 후 모여서 최종 투표를 진행합니다.
4번째 살인을 보지 않는 이유: 가스폭파 자살로 살인자가 동반 승리하는 상황을 막기 위함입니다.

스타 원작과 다른 점

마인크래프트판은 스타크래프트 추리게임 운명의 직업·단서·추리 구조를 바탕으로, 새 도구와 교란·구조 수단을 더한 버전입니다. 원작 설명글과 R0.8 E까지의 패치 내역을 기준으로 비교했습니다. 원작글에 없는 추가 아이템과 옛 버전에서 삭제됐다가 돌아온 아이템을 구분해 보세요.

괄호의 숫자는 아이템 한 개의 기본 사용 횟수입니다. 시작 지급 수량이나 파밍 등장 수량이 아닙니다. 원작의 모든 버전을 같은 규칙으로 단정하지 않으며, 아래 설명은 현재 서버의 규칙을 기준으로 합니다.

1. 원작글에 없는 추가 아이템 — 9종

아이템 / 사용 직업마인크래프트판에서 추가된 사용법추리할 때 주의할 점
비옷(1)
모든 직업		소지하면 몸 대신 비옷에 피가 묻습니다. 피 묻은 비옷은 넘기거나 쓰레기통을 통해 다른 사람에게 전달할 수 있습니다. 세탁해도 루미놀 잔류 반응이 남고, 과산화수소로 정화할 수 있습니다.받은 시민에게도 혈흔·잔류 반응이 나타날 수 있습니다. 피가 검출됐다는 이유만으로 직접 살인했다고 확정할 수 없습니다. 원작의 저격 방지 방탄복과는 다른 기능입니다.
호루라기(1)
모든 직업		우클릭하면 자신의 현재 위치를 참가자들의 미니맵에 알립니다. 알바생 전용 능력이 아니라 누구나 사용할 수 있는 별도 공용 아이템입니다.원작의 자기 위치 공개 기능과 비슷하지만, 현재 서버의 알바생 위치공유는 다른 사람을 추적하는 도구로 구분됩니다.
전파방해기(1)
살인마		살인 성공 후 남은 쿨타임이 31~120초일 때 사용합니다. 남은 시간 30초에 나올 사망 위치 공개와 화면의 사망 인원 증가를 숨깁니다. 실패 타이머에는 사용할 수 없습니다.살인 자체나 승리 카운트가 취소되지는 않습니다. 공개가 없었다고 살인이 일어나지 않았다고 단정하지 마세요.
구급키트(1)
모든 직업		사망 후 30초 이내 NPC 시체를 우클릭해 구조합니다. 성공하면 그 살인이 승리 카운트에 반영되지 않습니다. 플레이어 시체와 특수 즉사 NPC는 제외됩니다.원작에도 의사의 응급처치는 있었습니다. 구급키트는 그 능력을 새로 만든 것이 아니라, 더 짧은 시간 안에 누구나 구조할 수 있게 더한 공용 아이템입니다.
휴대용 금속 탐지기(1)
탐정·공대생·알바생		살아 있는 참가자 가까이에서 우클릭하면 금속 도구 소지 여부만 사용자에게 알려줍니다. 좌클릭으로 반응 목록과 예시를 볼 수 있습니다.구체적인 품목은 공개하지 않습니다. 금속 도구를 넘겨받은 시민도 반응하고, 독·수건 등은 반응하지 않으므로 양성·음성 어느 쪽도 단독 확정 근거가 아닙니다.
버려진 가방(1)
모든 직업		매 게임 왼쪽 또는 오른쪽 비상계단에 총 1개 생성됩니다. 조규철 자리는 제외합니다. 5칸 안에서 벽에 가리지 않았을 때 이름이 보이며, 가까이서 바라보고 좌/우클릭해야 줍습니다. 소지 후 클릭하면 독판별(3)·시체상태(∞)·돋보기(∞)·몸수색(1) 중 하나를 고릅니다.NPC나 지나가는 플레이어가 자동으로 줍지 않습니다. 선택한 조사 도구의 직업 제한은 그대로입니다. 가방은 일반 아이템으로 무게에 포함되고 훔치기 대상도 됩니다.
맹독다트(2)
살인마		우클릭으로 발사해 맞히면 10초 뒤 사망합니다. 사망 전 해독제로 생존할 수 있고 지연도구로 대기를 30초 늘릴 수 있습니다. 레이저사이트와도 연계됩니다.주입 독처럼 붙어서 먹이는 방식이 아닌 원거리 지연 독살입니다. 빗나가면 살인 실패 쿨타임이 생깁니다.
지뢰(1)
살인마		설치 후 10초 대기 → 30초 활성. 반경 1.5칸에서 현재 NPC/PLAYER 살인 모드에 맞는 대상을 감지합니다.지뢰 작동 중에는 다른 살인 도구를 사용할 수 없습니다. 아무도 걸리지 않고 끝나면 실패 120초 쿨타임이 생깁니다. 지연도구로 지뢰 시간을 늘릴 수는 없습니다.
원격C4기폭장치(1)
살인마		10초 설치 → 30초간 기폭 장치 활성. 장치를 우클릭하면 반경 2칸 안에서 현재 살인 모드에 맞는 대상 1명을 공격합니다. 활성 시간이 다 되면 누르지 않아도 자동 폭파됩니다.가스폭파처럼 범위 안 전원을 죽이는 도구가 아닙니다. 지연도구로 활성 시간을 30초씩 연장할 수 있고, 작동 중에는 다른 살인 도구 사용이 제한됩니다.

2. 원작에서 삭제됐다가 재도입·개편된 아이템 — 4종

아래 아이템은 완전 신규가 아닙니다. 원작의 예전 버전에 있던 이름·기능을 다시 활용하면서 현재 서버에 맞게 바꿨습니다.

아이템원작 패치 기록현재 서버의 사용법과 차이
수혈팩(1)R0.2에서 삭제되고 초시계가 추가됐습니다.살인마가 응고제를 좌클릭해 변환합니다. 출혈이 없는 시체를 우클릭하면 다시 피가 나오게 하여 혈흔 단서를 교란합니다. 이미 출혈 중인 시체에는 사용할 수 없습니다.
얼음(1)R0.8에서 삭제되고 누전방지퓨즈가 추가됐습니다. 원작의 누전방지퓨즈는 3분간 정전 시도를 막는 도구였습니다.현재는 발전기/퓨즈에서 사용합니다. 시민은 5분 동안 정전 발생 시 3초 뒤 자동 복구되게 하고, 살인마는 30초 뒤 정전을 예약합니다. 정전이 아예 시작되지 않는 방식과는 다릅니다.
소음기(3)R0.7에서 삭제됐습니다.리볼버·네일건 소지 후 우클릭으로 ON/OFF합니다. ON 상태의 실제 발사 3회까지 총성을 억제합니다. 단순히 켜는 순간이 아니라 실제로 총성을 억제한 순간 감지센서에 걸립니다.
녹음테이프(1)남·여 테이프가 있었으나 R0.7에서 삭제됐습니다.현재는 소리 선택 GUI를 씁니다. 시민은 호루라기·카톡, 살인마는 격발음·남/여 비명·폭발 등 모든 선택지를 고를 수 있습니다. 설정 후 우클릭하면 한 번 재생하고 소모되며, 좌클릭하면 다시 선택할 수 있습니다. 실제 무기가 아닌 일반 아이템입니다.

3. 원래 있던 아이템·능력의 주요 개편

항목원작 설명현재 서버의 차이
알바생 위치공유(1)장소 제한 아래 자신의 위치를 다른 플레이어에게 알립니다.다른 생존자를 추적합니다. 우클릭해 7칸 안 대상을 선택하고 5초 뒤 다시 우클릭하면 2~6회 중 보고 횟수가 정해집니다. 10초 뒤 첫 보고, 이후 30초마다 위치를 확인하며 대상 사망·접속 종료 시 중단됩니다. 자기 위치를 알리는 용도는 별도 호루라기가 맡습니다.
테슬라 자동차키(1)밖의 수상한 자동차에 접근해 즉시 살인합니다.밖의 노란 자동차에서 우클릭해 NPC 선택 GUI를 엽니다. 선택한 NPC는 15초 뒤 사망하며 플레이어를 고를 수 없습니다. 이동용 자동차키가 아닙니다.
레이저사이트(1)리볼버·수렵석궁으로 특정 외부 대상을 저격하며, NPC 모드에서는 최훈·이명호 중 무작위 공격을 합니다.202·501 저격 구역에서 대상 NPC를 선택합니다. 리볼버·수렵석궁 외에 맹독다트도 연계할 수 있고 저격 1회 후 사이트가 해제됩니다.
지연도구(1)살인 대기 30초 연장. 최종 패치에서는 중복 사용을 금지했습니다.여러 개를 연속 사용해 피살 대기·원격 C4 시간을 30초씩 연장할 수 있습니다. 일반 120초 살인 쿨타임이나 지뢰 시간은 연장하지 않습니다.
공구상자(1)시민은 손전등·초시계·망원경·비상열쇠 중 무작위 1개, 살인마도 정해진 보조 도구 중 하나를 얻습니다.시민의 4종 무작위 획득은 유지합니다. 살인마는 선택 GUI에서 녹음테이프·레이저사이트·증거인멸·지연도구·얼음·비옷·수면제·전파방해기·응고제·소음기 중 고릅니다. 전파방해기는 위치공개 ON일 때 보이고, 테이프가 자동으로 덤 지급되지는 않습니다.

4. 마인크래프트판에서 달라진 판정과 표현

  • 플레이어 살인 제한: 현재 서버는 고정 2회가 아니라 생존자가 4명 남을 때까지 허용합니다. 다른 사망이 없다면 8인 시작은 4회, 7인은 3회, 6인은 2회, 5인은 1회입니다. 4인 이하는 OFF이며 가스폭파는 예외입니다. 이는 현재 서버 규칙이며 원작의 모든 버전이 고정 2회였다는 뜻은 아닙니다.
  • 조작·대화 편의: 자동 이동·패트롤·수동 이동을 함께 제공하고 서로 속도를 맞췄습니다. 플레이어는 서로를 밀어 움직이게 하지 않고 장애물처럼 부딪힙니다. 본인 채팅과 타인 채팅의 본문 색을 구분하고, 허용된 사용자는 채팅용 표시 이름을 바꿀 수 있습니다. 패트롤이나 채팅이라는 개념 자체가 원작에 없었다는 뜻은 아닙니다.
원작에도 있던 요소: 경찰·의사·탐정·무당·소방관·연구원·공대생·알바생, 시체상태·독판별·돋보기·몸수색·관찰·은신·CCTV·루미놀, 응급처치·증거추리·강령술·긴급대피·범위분석 등은 완전 신규가 아닙니다. 원작 본문의 옛 직업 목록에 변호사가 있더라도 이후 패치에서 소방관으로 교체됐습니다. 기본 살인 도구와 지연도구·시체수거·레이저사이트도 원작을 계승합니다.

인게임에서 /help 또는 채팅에 help를 입력하면 이 도움말이 열립니다. 도움말의 아이템 이름은 수건(2), 독판별(3), 시체상태(∞)처럼 새 아이템의 기본 사용 횟수를 표시합니다. (∞)는 무제한입니다. 은신(1)은 1회 사용 후 3분 동안 ON/OFF 가능, 손전등(1)은 배터리 총 20초, 비옷(1)은 한 벌의 보호 효과를 뜻합니다. 인게임 이름의 (숫자)는 남은 사용 횟수이며 실제 아이템 수량과는 다릅니다. 독판별·관찰의 사용 횟수는 아이템별·사용자별로 관리됩니다.

독판별·관찰 넘겨주기 예시: 같은 도구라도 각 사용자는 처음 3회씩 사용할 수 있고, 사용 기록은 따로 남습니다. A가 1회 써서 A는 2회 남음 → B에게 넘겨 B가 2회 써서 B는 1회 남음 → 다시 A에게 돌려주면 A는 원래 기록대로 2회 남아 있습니다. 돌려받았다고 횟수가 초기화되거나 상대방 기록으로 바뀌지 않습니다. 도구 이름의 숫자는 현재 소지자의 남은 횟수를 표시합니다.

살인마 전용 기능

살인마에게 제공되는 기능입니다. 플레이어 감시는 자동 기능이며, 플레이어 살인과 NPC 살인은 같은 살인 모드 전환 아이템으로 선택합니다.

1. 훔치기

상대에게 바짝 붙어 일반 아이템 훔치기 / 살인 아이템 훔치기를 들고 우클릭하면, 해당 종류의 아이템 하나를 무작위로 훔칩니다. 원하는 아이템을 직접 선택할 수는 없습니다.

  • 일반 아이템 훔치기: 조사·보조용 일반 아이템을 훔칩니다. 버려진 가방도 포함됩니다.
  • 살인 아이템 훔치기: 살인 도구·보조도구·증거품 등을 훔칩니다. 넘겨준 수거 시체도 다시 가져올 수 있습니다.
  • 대상은 1.5칸 이내에 있어야 하며, 범위 안에 여러 명이 있으면 사용할 수 없습니다.
  • 횟수 제한은 없지만, 성공 후 두 종류 모두 1.5초간 재사용할 수 없습니다.

2. 넘기기

아이템 넘기기 ON/OFF를 우클릭해 켠 뒤, 상대에게 바짝 접근하여 넘길 아이템을 들고 버리기 키(기본 Q)를 누르면 상대 인벤토리에 몰래 넣습니다. 바닥에 버리는 기능이 아닙니다.

상대는 1.5칸 이내에 있어야 하며, 주변 2칸 안에 다른 플레이어가 두 명 이상 있으면 사용할 수 없습니다. 기본 지급 도구와 살인마 기능 아이템은 넘길 수 없습니다.

다시 우클릭하면 OFF가 됩니다. 성공한 넘기기는 1.5초 뒤 다시 사용할 수 있습니다. 넘긴 아이템은 해당 종류의 훔치기로 다시 가져올 수 있습니다. 받는 사람의 인벤토리가 꽉 차면 넘기지 않고 원래 소지자에게 남습니다.

3. 퓨즈 끄기

퓨즈 내리기 (1회용)를 들고 우클릭하면 즉시 정전을 일으킵니다. 살인마는 정전 중에도 시야를 확보하지만, 시민은 손전등 등의 도움이 없으면 시야가 차단됩니다.

옥상 발전기실 또는 주차장 A구역의 발전기(G/E) 표지판을 우클릭하면 정전을 해제할 수 있습니다. 시민이 설치한 얼음의 정전 방지 효과가 남아 있으면 3초 뒤 자동 복구됩니다. 사용한 아이템은 소모됩니다.

4. 플레이어 감시

살인마의 미니맵에는 오피스텔 안 생존 플레이어의 위치가 15초마다 빨간 표시로 4초간 나타납니다. 별도로 클릭하거나 아이템을 사용할 필요는 없습니다.

표시는 감시 시점의 위치이며, 실시간으로 따라 움직이는 표시는 아닙니다.

은신을 켠 플레이어는 감시에 표시되지 않습니다. 따라서 표시가 없다고 그 장소에 아무도 없다고 단정할 수는 없습니다.

5. 자살 / 포기

살인자 자살 (포기)를 들고 우클릭하면 게임을 포기합니다. 살인마의 정체가 공개되고 고립 엔딩으로 종료되며, 살인마 패배·시민 승리로 기록됩니다.

되돌릴 수 없으므로 신중하게 사용하세요.

6. 플레이어 살인

플레이어 살인 설정이 ON인 게임에서 살인 모드 전환을 우클릭해 PLAYER 모드로 바꾼 뒤, 살인 도구로 다른 플레이어를 공격합니다. 모드 전환 아이템 자체가 살인 무기는 아닙니다.

고정 2회 제한 없이 생존자가 4명 남을 때까지 가능합니다. 4명이 남으면 추가 플레이어 살인이 차단되고 NPC 모드로 바뀝니다.

다른 사망이 없다면 8인 시작은 최대 4명, 7인은 3명, 6인은 2명, 5인은 1명을 살해할 수 있습니다. 4인 이하로 시작하면 플레이어 살인은 OFF입니다. 가스폭파는 이 제한의 예외입니다.

7. NPC 살인

게임 시작 시 기본 모드는 NPC 모드입니다. 살인 도구를 사용해 살아 있는 NPC를 살해합니다. PLAYER 모드라면 살인 모드 전환을 우클릭해 NPC 모드로 돌아오세요.

근접 무기·주입 독은 가까이 접근해 좌/우클릭하고, 원거리·설치형 도구는 각 아이템의 사용법을 따릅니다. 도구에 따라 즉시 사망하거나 일정 시간 뒤 사망하므로, 바로 죽지 않았다고 실패한 것은 아닙니다.

살인 대기·쿨타임 중에는 다음 살인을 시작할 수 없습니다. NPC 모드에서는 일반 살인 도구로 플레이어를 살해할 수 없지만, 가스폭파는 예외입니다.

사용 방법과 예시

탐정·공대생·알바생이 살아 있는 참가자 가까이에서 탐지기를 들고 우클릭하면, 근처 참가자의 금속 도구 소지 여부를 사용자에게만 알려줍니다. 대상과 바짝 붙어서 검사하세요. 검사에 성공하면 탐지기 1개가 소모되며, 좌클릭은 소모 없이 설명서를 보여줍니다.

반응 대상이 하나라도 있으면 “삐빅!”과 금속류를 소지한 것 같다는 결과가 뜹니다. 어떤 아이템인지까지 알려주지는 않습니다. 반응 대상이 없으면 금속류를 소지하지 않은 것 같다는 결과가 뜹니다. 살인 도구를 넘겨받은 시민도 반응할 수 있어, 반응했다고 곧바로 살인마로 확정할 수는 없습니다.

  1. 리볼버 또는 식칼을 가진 사람: 반응합니다. 둘 중 어떤 아이템을 가졌는지는 알 수 없습니다.
  2. 비소와 수건만 가진 사람: 반응하지 않습니다. 금속 탐지기는 모든 살인 도구를 찾아내는 아이템이 아니므로, 무반응이어도 살인 도구가 없다는 뜻은 아닙니다.
  3. 리볼버테이프·자동무빙·패트롤만 가진 사람: 반응하지 않습니다. 리볼버테이프는 실제 총이 아니라 총소리만 재생하는 녹음테이프이고, 자동무빙·패트롤은 게임 조작용 아이템입니다. 여기에 실제 리볼버도 가지고 있다면 그 리볼버 때문에 반응합니다.

기타 팁

  1. 주사기와 손톱은 모두 살인증거 아이템으로 판정되어 몸수색 때 텍스트로 출력된다.
  2. 203호에서는 주사기가 나올 수 있고, 경비실에서는 손톱이 나올 수 있다. 살인자일 때 이를 이용해 혼선을 줄 수도 있다.
  3. 시체수거된 시체 역시 몸수색으로 노출된다. 다른 플레이어에게 넘기거나 사각/원형 쓰레기통에 버려도 살인 카운트는 오르지 않는다. 오피스텔 입구 잭오랜턴 시체 수거함에 넣을 때만 인정된다.
  4. 시작템이 겹칠 수 있으며, 겹템은 몸수색 시 1개로 인식한다. 예: 수건 / 수건 / 망치 / 청산가리로 시작했다면 몸수색에는 수건 / 망치 / 청산가리만 출력된다.
  5. 시체를 들고 있을 경우 관찰을 했다고 해서 무조건 무거움으로 뜨지 않는다. 시체도 아이템 1개로 취급한다.

자주 묻는 질문

실제 플레이 중 나온 질문을 현재 서버 기준으로 정리했습니다. 질문을 누르면 답변이 펼쳐집니다. 예전 로그의 인원 제한이나 당시 오류가 지금도 그대로라는 뜻은 아닙니다.

시작·승리·살인마 선정

1. 내가 살인자인지 어디서 확인하나요?

선정이 확정되면 본인에게 “당신은 살인자입니다” 안내가 나오고 살인마 전용 기능 아이템이 지급됩니다. yes/no를 묻는 후보 안내만으로는 아직 확정이 아닙니다. 직업 정보와 살인마 여부는 서로 다른 정보입니다.

2. 살인마는 별도의 직업인가요?

아닙니다. 경찰·의사·탐정 등 직업은 그대로 가진 상태에서 살인마 역할이 추가됩니다. “의사니까 살인마가 아니다”처럼 직업만으로 범인에서 제외할 수는 없습니다.

3. 5살 승리 모드는 무엇인가요?

살인마의 승리 목표가 살인 성공 5명인 모드입니다. NPC와 플레이어 살인이 포함되며 구조·시체 유기 등의 판정에 따라 인정되는 수가 달라질 수 있습니다. 전파방해기로 공개를 숨긴 살인도 승리 판정에는 남으므로, 화면에 공개된 인원만 세면 실제 목표와 다를 수 있습니다. 모여서 추리하는 순서는 게임 진행 흐름을 참고하세요.

4. 3명이면 살인마 승리 목표는 몇 명인가요?

참가 인원만으로 목표가 고정되지는 않습니다. 현재 게임은 3~8명이 참여할 수 있고, 살인 승리 목표는 시작 시 방장이 4·5·6·7·8살 중 선택합니다. 선택하지 않아 무작위로 정해진 경우도 시작 안내에 결과가 표시됩니다. 실제 적용 목표는 그 판의 안내를 확인하세요.

5. 7명으로도 게임이 가능한가요?

가능합니다. 현재 참가 범위는 3~8명입니다. 7명이라고 별도 모드를 설치할 필요는 없습니다. 플레이어 살인 ON/OFF와 승리 목표 등은 그 판의 시작 설정을 따릅니다.

6. 8명이면 플레이어 살인을 몇 번 할 수 있나요?

플레이어 살인 ON이고 다른 사망이 없다면 8인 4회, 7인 3회, 6인 2회, 5인 1회입니다. 고정 횟수를 주는 방식이 아니라 생존자가 4명 남을 때까지 허용합니다. 다른 원인으로 사망자가 생기면 추가로 가능한 횟수도 줄어듭니다. 4인 이하는 플레이어 살인 OFF이며 가스폭파는 별도 예외입니다.

7. 플레이어 살인 제한은 시스템 차단인가요, 암묵적인 룰인가요?

시스템에서 차단합니다. 일반 살인 도구로 생존자를 4명 미만으로 줄이는 추가 플레이어 살인은 허용되지 않으며, 한계에 도달하면 NPC 모드로 돌아갑니다. 예전 질문의 “3명”이 아니라 현재는 4명 기준입니다. 가스폭파는 플레이어 살인 ON/OFF와 이 제한의 예외입니다.

8. 살인마를 거절했는데 왜 다시 선정되나요?

후보를 한 번씩 돌았는데 모두 거절하거나 응답 시간이 끝나면 첫 번째 후보를 살인마로 지정하는 처리가 있습니다. 따라서 한 번 no를 입력했다고 그 판에서 절대로 살인마가 되지 않는 것은 아닙니다.

9. 전 판 살인마가 다음 판에도 살인마를 받아도 되나요?

자유입니다. 살인마를 연속으로 수락해도 되며, 한 판 쉬거나 거절해야 하는 의무도, 거절을 권장하는 규칙도 없습니다.

아이템 사용·획득·교환

10. 일반 아이템은 모든 직업이 사용할 수 있나요?

공용 아이템이 많지만 분류 이름만으로 사용 권한을 판단하면 안 됩니다. 전파방해기·수혈팩처럼 살인마 전용인 도구도 있고, 조사 도구에는 직업 제한이 있습니다. 아이템 설명의 “사용할 수 있는 직업”과 일반 아이템·직업 아이템 표를 우선 확인하세요.

11. 모든 아이템이 소모품인가요?

아닙니다. 시체상태(∞)·돋보기(∞) 등은 무제한이고, 수건(2)·독판별(3) 등은 사용 횟수가 제한됩니다. 괄호는 묶음 개수가 아니라 한 도구의 사용 횟수입니다. 은신(1)은 한 번 사용해 3분간 권한을 얻고, 손전등(1)은 총 20초의 배터리를 쓰는 식으로 효과가 다르므로 설명을 함께 읽으세요.

12. 다른 직업 아이템을 가져가도 되나요?

다른 직업용 도구도 파밍·쓰레기통 등으로 소지할 수 있고, 살인마가 훔치기로 가져가는 것도 가능합니다. 다만 가져왔다고 사용 직업 제한이 없어지지는 않습니다. 살인마의 훔치기와 일반 플레이어의 아이템 소지를 같은 기능으로 생각하지 마세요. 도구를 넘겨줄지 여부는 아래 확제템 설명도 참고하세요.

13. 아이템 넘기기 기능은 어떻게 쓰나요?

살인마 전용입니다. 넘기기 ON/OFF 도구를 우클릭해 켜고, 상대 1.5칸 안에서 넘길 물건을 든 채 버리기 키(기본 Q)를 누릅니다. 바닥에 떨어뜨리는 대신 상대 인벤토리에 넣습니다. 주변 2칸 안에 다른 참가자가 두 명 이상이면 사용할 수 없고, 성공 후 쿨타임은 1.5초입니다. 시스템 도구는 넘길 수 없으며 받는 쪽이 꽉 차면 원래 소지자에게 남습니다. 자세한 조건은 넘기기를 참고하세요.

14. 시민이 가진 아이템 제거는 어디에 쓰나요?

불필요한 아이템 한 개를 되찾을 수 없게 없애는 도구입니다. 아이템 제거를 우클릭한 다음 없앨 물건을 들고 버리기 키를 누릅니다. 기본·시스템 도구는 제거할 수 없습니다. 일반 쓰레기통에 보관하는 것과 달리 복구되지 않으므로, 살인 도구나 추리 단서를 이유 없이 없애지 않도록 비매너 기준도 확인하세요.

15. 파밍은 어떻게 하나요?

게임 중 등록된 슬라임 블록에 1.5칸 이내로 접근해 좌/우클릭하면 해당 장소의 후보 중 아이템 하나를 무작위로 얻습니다. 한 장소에서 목록 전체를 받는 것은 아닙니다. 비상계단의 버려진 가방은 블록이 아니라 바닥 아이템이지만, 이것도 바라보고 좌/우클릭해야 줍습니다. 파밍 장소표에서 후보를 확인하세요.

16. 직업 확인용 머리는 어디서 확인하나요? 안 보이면요?

게임에서 받은 [ 내 직업 정보 ] 머리에 마우스를 올려 설명을 읽으면 직업·성별·사용 도구를 확인할 수 있습니다. 최초 지급 위치는 인벤토리 두 번째 줄 맨 오른쪽입니다. 머리를 들고 좌/우클릭하면 미니맵 크기도 바꿀 수 있습니다. 다른 사람의 3인칭 화면에서 숨기는 것과 본인 인벤토리에서 사라지는 것은 다릅니다. 실제로 없어졌다면 그 직전 행동과 게임 단계를 관리자에게 알려주세요. 과거 질문만으로 원인을 단정하지는 않습니다.

17. 테슬라 자동차키는 어디서 사용하나요?

살인마가 오피스텔 밖 노란 자동차에서 우클릭하면 NPC 선택 창이 열립니다. 고른 NPC는 15초 뒤 사망하며 플레이어는 선택할 수 없습니다. 단순히 키를 들고 일반 근접 공격을 하는 도구가 아닙니다.

18. 자동차를 타고 빠르게 이동할 수 있나요?

테슬라 자동차키는 이동용 열쇠가 아니라 NPC 살인 도구입니다. 자동차를 운전해 이동 속도를 높이는 기능으로 사용하지 않습니다.

19. 긴급대피는 어떤 대상에게 쓰나요?

소방관이 2칸 안 살아 있는 NPC에게 우클릭해 대피시킵니다. 플레이어를 옮기거나 시체를 살리는 도구가 아닙니다. 이미 사망 대기 중인 NPC에게는 사용되지 않으며 대피가 끝난 NPC는 살인 대상에서 제외됩니다.

추리·판정·대화 규칙

20. 살인 위치 공개는 무엇인가요?

해당 설정이 ON이고 공개를 숨긴 살인이 아니라면, 살인 타이머의 남은 시간이 0:30일 때 피해자 신원 안내와 사망 위치 표시가 나오는 기능입니다. 살인 순간에 곧바로 뜨는 것이 아닙니다. 시체수거·전파방해기 등으로 공개가 숨겨질 수 있으므로 표시가 없다는 이유만으로 살인이 없었다고 확정하지 마세요.

21. 독살 대기 중 다른 대상을 공격해서 한 번에 2명을 죽일 수 있나요?

일반 살인 도구는 피살 대기나 살인 쿨타임 중에 다음 살인을 시작할 수 없도록 차단합니다. 독을 먹이고 기다리는 동안 다른 일반 도구로 추가 공격하는 방식은 사용할 수 없습니다. 가스폭파의 범위 내 다중 사망은 별도 규칙이지 이 제한을 우회하는 일반 연속 공격이 아닙니다.

22. 살인마 본인도 죽을 수 있나요?

가능합니다. 대표적으로 가스폭파 범위에 남아 있으면 살인마 자신도 휘말릴 수 있습니다. 또한 포기 도구를 사용하면 살인마 패배로 끝납니다. 가스폭파에 따른 동반 사망·승리는 그 판의 최종 판정을 따르며, 살인마라고 모든 사망에 면역인 것은 아닙니다.

23. 여기서 말하는 확제템은 무슨 뜻인가요?

여기서는 남에게 주면 내 신변이 위험해질 수 있는 도구라는 취지로 쓰는 플레이어 간 표현입니다. 예를 들어 은신을 넘기면 상대가 몰래 나를 죽일 수 있고, CCTV확인을 넘기면 내 동선을 추적해 플레이어 살인을 노릴 수 있습니다. 그래서 내가 보관하는 것과 남에게 넘기는 것을 다르게 판단할 수 있습니다. 어떤 도구를 이렇게 취급할지 등 세부 룰은 플레이어마다 다르며, 소지자에게 시스템이 시민 인증을 주는 기능은 아닙니다.

24. 얼음을 사용한 사람도 확제인가요?

얼음 소지·사용만으로 자동으로 시민 확정이 되지는 않습니다. 시민은 5분간 정전 발생 시 3초 뒤 자동 복구되게 하고, 살인마는 30초 뒤 정전을 예약하는 등 역할에 따라 효과도 다릅니다. 도구를 어떤 근거로 확제 취급하는지는 플레이어별 기준과 그 상황을 함께 봐야 합니다.

25. 근거 없이 감으로 관찰을 사용해도 되나요?

관찰 대상 선택은 자유입니다. 허용된 직업이 조건에 맞는 대상에게 모였을 때 사용하거나 몰래 확인할 수 있습니다. 다만 사용 횟수·거리·직업 제한은 유지되고, 결과를 언제 대화로 공개할지는 아래 대화 규칙을 따라야 합니다.

26. 살인 때 누구와 함께 있었는지 먼저 말해도 되나요?

추리대로 모였을 때는 동선·접촉·시작템·파밍·유언을 모두 공개할 수 있습니다. 흩어진 상태에서 알리바이를 먼저 흘리는 대화는 하지 않습니다. 단, 흩어져 있어도 시체를 발견했거나 1:1 상황이 되는 결정적인 사실을 발견했다면 발설할 수 있습니다. 단순 심증을 예외로 확대하지 마세요.

27. 노붙콜과 모였을 때·흩어졌을 때의 대화 규칙은 무엇인가요?

모여 있을 때: 모든 콜과 동선·접촉·시작템·파밍·유언 공개가 가능합니다.
흩어져 있을 때: 잡담만 가능합니다. 살인 타이머가 발생했을 때는 가급적 대화를 자제합니다.
예외: 시체 발견 또는 1:1 상황으로 이어지는 결정적인 상황을 발견한 경우에는 흩어진 상태여도 발설할 수 있습니다. 이는 플레이 규칙이며 평소 모든 채팅이 시스템으로 자동 차단된다는 뜻은 아닙니다.

28. 스파젠은 무엇인가요?

시작 아이템·파밍 아이템·시작 위치를 묶어 부르는 줄임말입니다. 그 정보를 말하는 것도 대화 규칙의 적용을 받으므로 모인 뒤 공개하고, 흩어져 있는 동안 간접적으로 흘리지 마세요.

조작·관전·접속 문제

29. 자동 이동은 어떻게 끄나요?

게임 중 오토무빙 상태 아이템을 우클릭하면 일시정지·재개할 수 있습니다. ON 상태에서 좌클릭은 끄기가 아니라 방향 전환이므로 구분하세요. 설정의 자동무빙 ON/OFF는 사용 설정 자체를 바꾸는 기능이며, 투표 중에는 자동 이동이 잠시 중단됩니다.

30. 오토무빙 명령어가 안 되는데 어떻게 켜나요?

우선 톱니바퀴 모양 [ 설정 ] → 자동무빙 오른쪽 ON/OFF 버튼을 이용하세요. 설정이 켜져 있어도 상태 아이템은 일시정지일 수 있습니다. 다시 켜기 대기 시간·인벤토리 공간 부족·투표 중 잠금 안내가 있다면 해당 조건부터 확인하세요. 해결되지 않으면 현재 로비/게임/투표 중 어느 단계인지와 표시된 문구를 관리자에게 알려주세요.

31. 왜 바로 관전 모드로 들어가지 못하나요?

플레이 중 죽은 사람은 즉시 자유 관전이 되는 것이 아니라 살인 타이머의 남은 시간이 0:30이 될 때 관전 모드로 전환됩니다. “죽고 30초 뒤”와 다릅니다. 반면 이미 진행 중인 게임에 로비의 참여 아이템으로 들어온 사람은 중도 관전으로 참여합니다. 타이머 조건이 지났는데도 전환되지 않으면 관리자에게 상황을 알려주세요.

32. 리소스팩은 어디서 다시 받나요?

서버 목록에서 해당 서버를 편집해 서버 리소스팩을 사용하도록 설정하고 재접속하면 서버가 지정한 최신 팩을 다시 요청합니다. 예전에 따로 받은 파일이 있다면 현재 서버 팩과 같은 버전인지 확인하세요. 수동 파일이 필요하면 관리자에게 최신 링크를 요청하고, 오래된 업로드 주소를 임의로 골라 쓰지 마세요.

33. 1.21.8과 1.21.11 모두 리소스팩이 안 되면 어떻게 하나요?

두 버전에서 안 된다는 사실만으로 버전 문제라고 단정할 수는 없습니다. 서버 리소스팩 허용 설정과 다운로드·적용 실패 문구를 먼저 확인하고, 재접속해도 같다면 실패 직후 클라이언트 latest.log를 관리자에게 전달하세요. 각자 다운로드·캐시·게임 폴더·다른 팩 구성이 달라 같은 증상도 원인이 다를 수 있습니다. 과거 한 사람의 오류 원인을 모든 사용자에게 적용하지 않습니다.

34. 문제 확인을 위해 로그 파일의 무엇을 보내야 하나요?

오류가 발생한 시각, 사용 버전·런처, 화면의 오류 문구와 해당 실행의 logs/latest.log를 함께 보내주세요. 일반 설치는 %appdata%\.minecraft\logs\latest.log에 있지만 별도 프로필·런처는 게임 폴더가 다를 수 있습니다. 의미를 알 수 없는 깨진 문자로 붙여넣기보다는 파일로 전달하세요. 로그인 토큰·비밀번호·개인정보가 포함됐다면 가리고 공개 채팅이 아닌 관리자에게 보내주세요.

비매너 기준

시민 관련 비매너

  1. 피가 터지고 있는 시체에 부검직 또는 확제가 아님에도 붙어서 피를 묻히는 경우.
  2. 아무 근거와 합의 없이 부검도 못한 시체에 증거인멸을 사용하는 경우.
  3. 본인의 살인아이템을 근거 없이 쓰레기통에 버리는 경우.
  4. 몸수색을 사용했을 때 해당 플레이어의 살인아이템을 즉시 말해버리는 경우. 부검 결과와 관련된 도구 유무와 도구 개수만 말할 수 있고, 공개는 추리대나 1대1 같은 상황에서 동의를 구하고 진행.
  5. [노붙콜] 움직이지 않는 NPC에 수면제를 사용하는 경우.
  6. [노붙콜] 흩어진 상태에서 동선·접촉·시작템·파밍·유언을 직접 또는 간접적으로 흘리는 경우. 흩어져 있을 때는 잡담만 가능하고 살인 타이머 발생 시 가급적 대화를 자제한다. 단, 시체 발견 또는 1:1 상황이 되는 결정적인 상황 발견은 발설 가능하다. 모였을 때는 위 정보와 모든 콜을 공개할 수 있다.
  7. 살인자에게 역 1대1이 잡혀 억울하다는 이유로 흩어지지 않고 추리대에서 잠수하는 경우. 탈주도 이에 해당.

살인자 관련 비매너

  1. 시민과 짜고 치는 경우. 친구 또는 지인과 협동해 누군가를 바보로 만드는 행위.
  2. 1살 이후 고의적으로 살인을 하지 않거나 그에 준하는 행위를 하는 경우.
  3. 무지성 연속 살인을 하는 경우. 단, 살인마 역할의 연속 수락 자체는 자유이며 한 턴 거절 의무나 권장 규칙은 없다.
  4. 플감에 시민들이 자주 겹쳐 있다고 분위기를 흐리며 반포기 상태로 플레이하는 경우.
  5. 뉴비 코스프레로 용의선상에서 배제되도록 하는 경우.
